# Fonts

Bundled so the app looks the same offline and never asks Google's servers for anything at run time.
They were downloaded once from Google Fonts on 2026-09-19 (Latin subset) and are served by Streamlit's
static file serving (see `.streamlit/config.toml`).

| Font | Used for | License |
|---|---|---|
| **Inter** (Rasmus Andersson) | Body text | SIL Open Font License 1.1, see `Inter-OFL.txt` |
| **Barlow Condensed** (Jeremy Tribby) | Headings and big numbers | SIL Open Font License 1.1, see `BarlowCondensed-OFL.txt` |

The OFL allows using and redistributing these fonts with an app, provided the license text stays with them.
